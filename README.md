# Prometheus + Grafana Monitoring Demo

> Простой и быстрый способ настроить мониторинг серверов с красивыми графиками и алертами.
## О чём этот проект?

Это мой учебный мини-проект, где я собрал всё самое нужное для мониторинга серверов.
Здесь Prometheus собирает метрики, node_exporter отдаёт данные о системе, а Grafana показывает всё это на удобных дашбордах.
Плюс — настроены алерты, чтобы не пропустить перегрузку процессора, нехватку памяти или места на диске.
## Что тут можно?

- Следить за состоянием сервера: сколько занято CPU, памяти, диска.
- Смотреть красивые графики в Grafana.
- Получать алерты, если что-то идёт не так (например, процессор загружен на 100%).
- Всё запускается одной командой через Docker Compose — не надо ничего настраивать вручную.
## Как устроен проект?

- `docker-compose.yml` — всё запускается отсюда, одной командой.
- `prometheus.yml` — настройки Prometheus: что и откуда собирать.
- `alert_rules.yaml` — тут лежат правила для алертов.
- `screenshots/` — папка с примерами того, как всё выглядит.
## Как запустить?

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/Valera1488-s/prometheus-monitoring.git
   cd prometheus-monitoring
   ```

2. Запустите всё одной командой:
   ```bash
   docker compose up -d
   ```

3. Откройте в браузере:
   - Prometheus: [http://localhost:9090](http://localhost:9090)
   - Grafana: [http://localhost:3000](http://localhost:3000)  
     (логин/пароль: admin/admin — стандартные, не забудьте поменять для продакшена!)
## Как проверить, что алерты работают?

- Чтобы нагрузить процессор, выполните:
  ```bash
  for i in {1..12}; do yes > /dev/null & done
  ```
- Чтобы остановить нагрузку:
  ```bash
  killall yes
  ```
- После этого посмотрите алерты в Prometheus или Grafana — если всё настроено, увидите сработавшие предупреждения.
